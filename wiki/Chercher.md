# Chercher

## La barre de recherche

Tapez trois lettres. Elle cherche **sans que vous ayez à savoir où** :

* le texte océrisé du document ;
* l'émetteur, le classement, le nom du fichier ;
* les champs extraits (numéro, montant) ;
* **les choses désignées** — taper « Clio » retrouve la facture du garage, qui ne
  contient pourtant nulle part ce mot : elle désigne le véhicule.

Le **périmètre** se choisit à côté du champ : toute la GED, le type ouvert, ou ce
que les filtres en cours laissent voir.

> 📸 **Capture à placer ici — `images/recherche.png`**
> Les résultats d'une recherche sur « Orange », montrant des documents de types
> différents et, sous chacun, **pourquoi** il est sorti (émetteur, texte, champ).

## Les filtres de colonne

Sous les intitulés du tableau. Chacun propose les valeurs réellement présentes —
pas une liste théorique. Les intitulés et cette rangée **restent visibles** quand
on fait défiler.

Le vocabulaire est le même partout : `categorie`, `date_document`, `date_import`,
`statut`, `nom_fichier`, `texte`, `meta:<clé>`, `lien:<table>`.

## Grouper

« Grouper par » replie le tableau par catégorie, par émetteur, par année. Le
repli proposé par une vue peut être changé en lisant : c'est celui qui regarde
qui décide comment il parcourt.

## Les vues enregistrées

Une combinaison de filtres qu'on retrouve d'un clic : « Factures sans titulaire »,
« Documents de l'année ». Depuis le registre, **Enregistrer la vue**.

Une vue peut être **partagée** avec le foyer ; les droits par rôle décident de
qui la voit.

> 📸 **Capture à placer ici — `images/vues.png`**
> La navigation avec plusieurs vues enregistrées, et le registre affichant l'une
> d'elles avec ses critères actifs.

## Ce qui n'apparaît pas dans les résultats

* Les documents **incomplets** : ils attendent au Centre d'analyse, et le
  registre ne les montre pas — les afficher classés laisserait croire que le
  classement est fait.
* Les documents que vos **droits** ne vous laissent pas voir. Ils n'apparaissent
  pas plus dans les comptages : un total ne doit pas révéler ce qu'on ne peut pas
  lire.
